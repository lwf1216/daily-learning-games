# Privacy

Daily Learning Games is designed to work without an account or application
backend.

- Learning progress and preferences are stored in the current browser's
  `localStorage`.
- The application code does not upload learning progress, names, answers, or
  exported backups.
- A backup is created only when the user explicitly downloads one. The user is
  responsible for storing and sharing that file safely.
- Clearing browser data removes local progress unless a backup was exported.
- A hosting provider may process ordinary HTTP request information according to
  that provider's own policies. Repository maintainers should review their
  hosting and analytics settings before deployment.

Do not include real names, contact details, credentials, or private learning
records when opening an issue or contributing code.
